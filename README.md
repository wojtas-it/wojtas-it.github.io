# wojtas.it

Personal portfolio site, live at [wojtas.it](https://wojtas.it).

Built with plain HTML, CSS and JavaScript, no framework, no build step.

## Stack

- `index.html` - page structure
- `css/style.css` - all styling
- `js/main.js` - language switching, filters, project grid rendering
- `content.js` - all text and project data (PL / EN / DE)

## Running locally

Open `index.html` directly in a browser, or:

```
npx serve .
```
